# 27 — RIBBON

Build a standalone Los Niños photo archive as a continuous, gently curved ribbon of paper prints on navy. A large cream masthead, restrained archive metadata, and quiet controls surround the images. Position every print along the same S curve; interpolate size, angle, and depth as the ribbon moves. The centered print opens a full-image dialog.

Interaction: horizontal pointer dragging with snap-to-photo on release, previous/next controls, arrow keys, Home/End, touch support, and Escape to close the viewer. Provide a reduced-motion mode and visible keyboard focus. Use only supplied local photos and fonts, with no factual marketing claims.

Validation: check JavaScript syntax and every referenced local asset. Parent performs browser and viewport QA.
