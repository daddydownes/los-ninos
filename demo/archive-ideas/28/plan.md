# 28 — Spread the stack

A navy and cream contact-sheet experience. Six physical-looking prints begin in a compact overhead pile. A vertical brass-colored handle is the primary control: pulling down continuously interpolates each print into a three-column, two-row editorial grid; pulling up gathers the pile again. Numbered captions become visible as the prints separate.

A visible native range control supplies keyboard support and an alternate touch input. The draggable handle captures pointer movement. Clicking any print opens a full-view dialog with next/previous navigation and Escape/close behavior. Responsive geometry is calculated from the stage width, including at 375px, rather than allowing the grid to overflow. Motion is direct manipulation; reduced-motion disables decorative transitions.
